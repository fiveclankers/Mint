# Mint

Personal backup of my old Linux Mint (Cinnamon) desktop setup.

## What is in here

- `applets/`, `spices/`: Cinnamon panel applets and extensions
- `kitty.conf`: Terminal settings
- `config.fish`, `.zshrc`, `.bashrc`: Shell configs and fish functions
- `variety.conf`: Wallpaper rotation
- `themes/`, `icons/`: GTK styling and icon sets

## Quick notes

Old personal backup from when I ran Mint. Copy what you need, but do not blindly dump the whole tree into your home directory.
